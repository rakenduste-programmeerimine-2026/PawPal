# PawPal mobile-first front-end demo

A dark, responsive React/Vite mockup for a pet walking and pet sitting marketplace.

## Run locally

1. Install Node.js (LTS).
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open the local URL Vite prints (usually `http://localhost:5173`).

## Demo functionality
- Toggle dog walking / pet sitting service type
- Search caregivers by name, title, or pet/service tag
- Sort sample caregivers by recommendation, rating, distance, or price
- Save/unsave caregivers
- Open booking request modal and submit a demo request
- Switch bottom navigation tabs

All profiles, pricing, distances, booking actions, and verification indicators are sample/demo data. No backend, authentication, real map, payment, or actual booking submission is connected.
